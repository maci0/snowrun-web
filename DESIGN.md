# Design

Match the Android app as requested: original welcome_hero, launcher and Yuki assets; white surfaces, navy primary controls and Roboto typography. Preserve observed onboarding copy, native rounded buttons, map-first experience and Journal/Friends/Rewards/Me destinations. Responsive desktop extends the same visual system. Exact visual parity is limited by screens that cannot be observed in the emulator. Fake GPS is user requested.

Official Play Store references also establish orange map actions, a pale-orange experience banner, purple planned routes, and a navy snowmile balance panel. These observations guide the browser adaptation.
